# AnswerQuickReply · 答疑 QR

Discord + Vencord 自定义插件，支持 Windows 桌面端和 Chrome / Edge 网页扩展。保存图文答复，为它们配置关键词，右键提问后引用并发送；界面始终在 Discord 内。

## 使用

1. 网页端加载包含本插件的 Vencord 扩展后刷新 Discord 页面。桌面端首次安装本地模块时，从系统托盘完全退出 Discord，再重新打开。
2. 设置 → Vencord → Plugins，搜索 `AnswerQuickReply` 或“答疑”。本版本默认启用。
3. 右键已有答复 → **保存为答疑 QR**。文字、图片会带入编辑器；填写名称与触发词，再保存。可以继续添加本地图片或粘贴截图。
4. 右键问题 → **答疑 QR**。二级菜单最上方可搜索本地及已授权读取的云端 QR 的名称、触发词、辅助词及回复正文；清空搜索恢复推荐 / 收藏，点击条目引用原消息发送。菜单搜索框的 Enter（含中文输入法确认）不会发送。**搜索 / 预览全部 QR** 打开选择面板：左侧列表，右侧发送预览；面板搜索框可用 ↑ ↓ 切换、Enter 发送（中文输入法选词时不会触发）。
5. 图片提问使用 **识别图片并查找 QR**。多张附件可以选择识别哪张；识别完成只更新候选，不会自动发送。
6. 列表中每条 QR 悬停或选中时右侧出现 **×**，点击即删除，无需进入编辑页；选择面板和管理面板都可使用。删除后底部提示可 **撤销**；失败则显示原因并保留条目。
7. 插件设置或消息右键的 **管理答疑 QR** 可编辑、删除、导出和导入。备份是包含全部图片的 JSON 文件；导入合并库，相同 ID 用导入项更新。
8. **查看收录的原消息** / **收录来源** 会关闭 QR 面板，在 Discord 内跳转并定位原消息，不打开外部浏览器。
9. 在选择／管理面板右键本地或云端 QR，可选择 **收藏／取消收藏**；详情页的星形按钮也可操作。两种来源的筛选标签统一为 **收藏**。消息右键菜单显示本地收藏和带「云端」标识的云端收藏。

云端收藏是个人本机标记，按答疑库地址、贡献服务登录账号和条目 ID 保存，不修改共享库，也不复制正文或图片到本地库。服务器条目的标星不再代表个人收藏。同一条目更新后保留收藏；条目删除、退出登录或权限失效时不再显示或发送云端收藏，重新授权后可恢复仍存在的收藏。「保存到本地」仍用于创建可离线使用的独立副本。云端收藏不包含在本地 QR 导出中，也不会在桌面／网页之间自动同步。

首次启用时本地 QR 库为空，不在插件文件中内置答复。选择面板默认显示社区云端库（需答疑身份组，见下文）；没有身份组时可切换本地，自行收录、新建或导入。升级会一次性移除旧版中未改动内容的默认示例，保留你新增或编辑过的 QR。

匹配任意触发词即可推荐；辅助词显示“可能相关”。数字关键词有数字边界，全角数字会归一化；重复识别不会产生重复条目。推荐表示规则命中，不代表已经确定故障原因。

## 社区云端库（仅答疑成员）

默认云端地址写在 `remote.ts` 的 `DEFAULT_REMOTE_URL`。社区云端库**只对指定 Discord 服务器中拥有答疑身份组的成员开放**：点击「Discord 登录 / 投稿」→「使用 Discord 登录」，在浏览器输入插件面板显示的 4 位配对码，再点击「继续 Discord 身份授权」。授权当前 Discord 账号后，插件会自动完成登录，无需复制登录码。身份组由服务端向 Discord 查询，插件无法也不需要自行判断；没有身份组的账号拿不到登录码，可继续使用本地 QR。退出登录会同时清除已下载的云端缓存；「退出所有设备」还会撤销这个服务账号的全部登录会话。选择答疑面板默认「云端」，管理面板默认「本地」。插件文件不内置 QR 内容；云端内容使用与本地备份相同的 JSON 格式，图片内嵌于条目。

1. 打开云端面板时自动获取。成功缓存 5 分钟（包括空库）；失败后的自动重试至少间隔 60 秒，需重新打开或切换到云端触发，不在后台轮询。手动「刷新答疑库」可以立即重试，多面板共享同一次请求。空库显示「暂无云端 QR」。
2. 云端条目可搜索、按正文 / OCR 推荐、预览并引用发送；不会自动发送消息。社区库详情可「编辑云端」，保存后替换原条目；普通读取不会上传或同步本地库。「保存到本地」生成新 ID，不覆盖同 ID 的本地 QR。自定义 HTTPS JSON 库仍只读。
3. 刷新失败保留同一连接上次成功获取的缓存并标记过期；更换连接或停用插件清空缓存、取消旧请求，旧结果不会回填。
4. 「高级设置」仍可保存自定义 HTTPS 地址及可选密钥，也可「恢复默认云端」。既有其他自定义地址保持不变；未配置、旧空配置自动采用社区地址，旧社区配置的密钥会被清除。向默认社区地址只发送插件自己的登录会话（`Authorization: Bearer`），从不发送 Discord 账号 token 或自定义密钥。自定义密钥仅存在独立本地配置，不进入 QR 备份。
5. 云端页上方的「全部导入本地」可一次复制列表内所有图文 QR；搜索或切到推荐 / 收藏列表后，按钮变为「导入当前结果」。相同名称、正文、关键词、图片和来源的内容会跳过（忽略 ID、收藏和编辑时间），已有本地 QR 不会被覆盖。整批校验后一次保存，超出本地 300 条或总图片容量限制时整批失败，不会只导入一半。导入后可离线使用，并可在右键菜单搜索；之后的云端更新不会自动修改这些本地副本。

下载限制为 30 秒、最多 32 MiB，并完整校验条目数量、字段、图片和 JSON 版本。地址必须使用 HTTPS，禁止带用户名 / 密码或重定向；请求不带 Cookie 或来源页面地址。自建服务需返回 JSON Content-Type，并允许 Discord 网页跨域请求。桌面与网页配置分别保存在各自本地环境，备份迁移只包含本地 QR。

默认地址迁移、禁止发送旧社区密钥、缓存 / 失败间隔、并发去重、停用重启、严格校验及本地库隔离已通过实际模块的模拟回归。服务端身份组鉴权有独立测试（见服务端仓库）。登录后的 Discord 界面、真实回复发送及 Android 网络仍需实机验证。

桌面版通过插件原生模块向 Vencord 注册社区 HTTPS 地址的 `connect-src` 权限，供云端下载与贡献请求使用；不关闭 Discord 的整体内容安全策略，也不增加脚本或图片来源权限。升级此修复后，需要从系统托盘**完全退出 Discord 再打开**，仅 Ctrl+R 刷新不足以载入新的原生 CSP 规则。若旧版出现 `Failed to fetch`，即使服务器在线，也可能是客户端 CSP 阻止了连接。

## 投稿与审核

### 编辑已发布的云端 QR

进入「云端」列表 → 选中条目 →「编辑云端」→ 修改标题、正文、图片、触发词或辅助词 →「保存到云端」。保存直接提交修改，不需先导入本地，也不增加一条副本。

- 仍需答疑身份组登录。`autoPublishIds` 白名单账号直接替换；其他答疑成员进入审核，通过前原内容保持不变，驳回不会修改云端库。
- 「我的提交 / 审核」区分【新增】与【修改】。审核修改时显示当前云端版本与申请内容的标题、正文、关键词、辅助词、图片数量和来源链接对比，正文逐行标记增删。通过即替换原条目；所有用户使用相同的共享 QR ID。只有审核员可取得当前版本的对比内容。
- 编辑开始时固定条目 ID 和版本。保存或审核时发现已被别人更新／删除，服务返回冲突并保留当前云端内容，编辑器不会关闭。请复制保留自己的草稿，刷新云端库后基于新版重新编辑；旧的待审修改应驳回后重新提交。
- 保存成功刷新社区云端缓存；已导入本地的副本不自动同步。网络结果不明时保留编辑器，直接重试相同内容会复用请求 ID，不重复替换。
- 需要配套的新服务端（`/contributions/status` 返回 `cloudEditing: true`）。旧服务端或自定义 JSON 地址不会被当成可编辑服务。

客户端编辑回归：安装 Vencord 依赖后，设置环境变量 `VENCORD_DIR` 为其源码目录，运行 `node answerQuickReply/tests/cloud-edit.cjs`。测试实际编辑器与提交模块的目标固定、重试、待审提示和本地隔离，使用模拟宿主及 HTTP。

### 新增投稿与登录

本地 QR 详情可「提交到云端」，工具栏「Discord 登录 / 投稿」打开我的提交与审核。这部分仅连接社区贡献服务，独立于自定义云端地址。登录同时用于读取社区云端库；本地 QR 的保存、搜索和发送无需登录。

- 管理员尚未配置 Discord OAuth 应用时，显示「管理员尚未开通提交」，不会要求普通用户填写服务器信息。
- 首次点击「使用 Discord 登录」，插件显示仅本次有效的 4 位配对码。浏览器确认页不显示这个码，需要从自己的插件中读取并输入；输错一次就作废，须重新发起。配对成功后点击授权链接，完成当前账号的身份授权（`identify` 与 `guilds.members.read`：只读取用户名和答疑服务器中的身份组）。保持面板打开，通常 5 秒内自动完成登录；可取消，10 分钟超时。浏览器账号不同会拒绝登录。不要打开别人转发的登录链接或把配对码告诉他人。旧版登录码方式保留在折叠的兼容选项中，插件不读取 Discord 客户端 token；旧客户端不支持配对时需更新，或使用一次性登录码。
- 投稿前预览并确认固定的文字、图片和关键词；普通投稿等待审核，服务授予免审权限的账号可以直接发布。网络结果不明时，同一账号、同一内容的重试复用持久化请求编号，防止重复投稿。
- 审核入口由服务返回的权限控制；审核者先查看实际图文，再通过发布或填写说明驳回。服务器负责最终授权，插件不按本地 Discord ID 判定管理员。发布成功后刷新当前社区云端库。
- 会话仅保存在本机独立存储，不进入 QR 导出；过期、HTTP 401 或退出登录会清除本地会话。「退出所有设备」撤销当前账号在贡献服务中的所有会话，其他设备需重新登录。审核员和免审账号会话最长有效 24 小时；发布与审核通过共用服务端每账号每小时的发布额度，默认 30 次。停用插件取消在途操作，不会自动登录、投稿或审核。

投稿、权限、会话、失败重试、图文预览与审核流程已通过 mock 回归；服务是否开放以面板读取的实际状态为准。真实账号授权、投稿和审核的端到端流程仍需在客户端完成验证。

## 本地数据与 OCR

QR 保存在 Vencord 的 IndexedDB，键为 `AnswerQuickReply_library_v1`，与插件源码分开。图片保存实际字节，不依赖历史附件链接。清理 Discord 本地站点数据可能清除该库，请定期导出。

桌面端采用 Windows 自带 OCR；网页端采用随包内置的 Tesseract.js 引擎与英文、简体中文语言包，通过浏览器 Worker 在本机识别，无需 API Key 或运行时下载识图资源。网页引擎首次识别时才启动，空闲一分钟后释放内存；停用插件会结束识别线程。图片不会上传到外部 OCR 服务；首次读取历史附件仍需从 Discord 下载。

支持 PNG、JPEG、WebP、GIF。网页端把动画图转换成一帧，并按需缩小超大图片；桌面端 WebP/GIF 解码依赖 Windows 编解码器。识别失败时可改用清晰的 PNG/JPEG。识图缓存仅在当前运行期间保存，最多 50 项。

2026-10-10 移植复查修复：停用网页插件时立即取消进行中的附件下载，丢弃晚到的读取结果；本地图片读取被中止或返回无效结果时明确报错，避免编辑器一直等待。离线测试中，普通与 SIMD 引擎都能从长截图识别 `524`、`cloudflare`、`errorcode_524`；这是引擎测试，不代表所有浏览器或 Android WebView 的宿主接口都已验证。

插件设置提供“检查本地 OCR”。桌面端若提示缺少本地模块，需要完全退出并重开 Discord；缺少语言包时可在 Windows 语言设置安装光学字符识别组件。网页端不依赖这些 Windows 组件，使用本插件配套的 Vencord 扩展即可。

桌面端、浏览器及不同浏览器个人资料使用独立的本地存储，不会自动同步 QR。在原客户端“导出备份”，再到新客户端“导入”即可迁移图文内容。网页附件若因链接过期或跨域限制读取失败，会提示原因，可重新上传附件或在编辑器中添加已下载的本地图片。

容量：最多 300 条 QR、每条最多 10 张图、单图 10 MiB、全库图片 64 MiB；回复文字最多保存 4000 字符，发送时检查当前账户的 2000/4000 字符限制。关键词每行一个，也支持中英文逗号或分号分隔。

## 发送行为

- 菜单首次打开时固定原消息的频道、ID、作者、正文和附件。列表移动、菜单刷新、切换频道、等待识图或图片上传不会改变该菜单 / 面板的回复目标；下次右键才选取新目标。
- 图片上传全部成功后，与文字一起发送为一条引用回复。失败不会先发半条文字。
- 默认不提醒被回复的人，可在设置或面板中开启。不会解析正文中的批量提及。
- 防止同一目标并发发送；服务器未确认时提示先检查频道，避免重复回复。
- 仅收录消息自身的 PNG/JPEG/WebP/GIF 附件。外站嵌入图片可先保存到本地，再手动加入 QR。

## 源码安装 / 开发

发行文件的用途如下；未标记 Kettu 的插件源码和扩展包用于 Vencord。

| 文件 | 用途 |
| --- | --- |
| `AnswerQuickReply-web-chrome-edge.zip` | 已编译的完整 Chrome / Edge 扩展，解压后加载扩展目录。 |
| `AnswerQuickReply-vencord-desktop-source.zip` | 桌面 Vencord 插件源码，需要加入现有源码后编译。 |
| `AnswerQuickReply-universal-plugin-source.zip` | 桌面 / 网页共用插件源码，包含浏览器 OCR 资源。 |
| `AnswerQuickReply-source.zip`、`AnswerQuickReply.zip` | 当前通用插件源码的同内容别名。 |
| `AnswerQuickReply-web-build-source.zip` | 此次网页扩展的完整构建源码，不含依赖目录。 |

文件名包含 `legacy`、`ui-redesign` 或 `reply-target-fix` 的包是历史备份，未包含本次社区云端与投稿功能。

将整个 `answerQuickReply` 文件夹放入 Vencord 的 `src/userplugins/`，按官方自定义插件流程编译并部署。升级旧源码时移走原 `answerQuickReply.desktop`，不要同时保留两个同名插件。无需新增 npm 依赖，必须连同 `vendor/` 一起复制。
